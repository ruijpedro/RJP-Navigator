# RJP Navigator WebApp V4.0

GitHub Pages: https://ruijpedro.github.io/RJP-Navigator/ após publicação em Actions.

Novo separador **Ativos ferroviários**, com todos os tipos de infraestrutura numa única tabela. Mantém a geometria incluída para funcionamento offline da pesquisa no eixo; mapa de fundo e pesquisa de estradas requerem acesso à internet. A sincronização de ativos só funciona depois de publicar o serviço de leitura Google Apps Script e ativar `public/config/ativos-sync.json` uma única vez.

Ver `GUIA-V4-ATIVOS-E-SINCRONIZACAO.md` para a folha Google Sheets, esquema, exemplos e configuração. Não introduzir dados pessoais/confidenciais na base publicada.
